# هم‌سفر من

وب‌اپ راهنمای سفر با **Python + Flask + SQLite**.

## اجرا

```bash
pip install -r requirements.txt
python app.py
```

بعد در مرورگر باز کنید: http://127.0.0.1:5000

## امکانات

- شش شهر (اصفهان، شیراز، یزد، تبریز، مشهد، رشت) با تصویر پس‌زمینه هر شهر
- مکان‌های دیدنی و رستوران‌ها، دسته‌بندی‌شده بر اساس بودجه (اقتصادی / متوسط / لوکس) با فیلتر
- ثبت نظر، امتیاز ستاره‌ای و آپلود عکس سفر برای هر شهر (ذخیره در SQLite)
- فاصله از تهران، زمان رسیدن، بهترین ساعت حرکت، بهترین فصل و شهرهای میان‌راه
- دستیار هوشمند: سؤال‌های آماده که با یک کلیک جواب می‌دهند
- پرسش‌نامه سفر: تعداد نفرات، کودک، بودجه، مدت، ماه، وسیله، هدف و سرعت سفر؛ خروجی: رتبه‌بندی شهرها، برآورد هزینه و برنامه روزانه
- مقالات: غذاهای محلی، بودجه سفر، فاصله جاذبه‌ها، تجربه مسافران
- صفحه «درباره ما» با متن معرفی پروژه و چشم‌انداز آینده

## ساختار

| فایل | کاربرد |
|---|---|
| `app.py` | مسیرها، دیتابیس نظرها، پرسش‌نامه، دستیار |
| `data.py` | شهرها، مکان‌ها، رستوران‌ها، قیمت‌ها، فاصله‌ها |
| `templates/` | صفحات HTML (راست‌چین) |
| `static/` | CSS، JS و تصاویر شهرها |
| `tools/make_art.py` | تولید تصاویر SVG شهرها |

## تغییر عکس شهرها

عکس واقعی را با نام شهر در `static/img/cities/` بگذارید (`esfahan.jpg`، `shiraz.webp` و ...). عکس واقعی به SVG اولویت دارد.

## اضافه‌کردن شهر جدید

یک آیتم جدید به `CITIES` در `data.py` اضافه کنید (همان فیلدهای بقیه شهرها)، مختصات آن را در `COORDS` داخل `app.py` بگذارید و فاصله‌اش را به `_KM_PAIRS` اضافه کنید.

## نکته مهم درباره داده‌ها

قیمت‌ها، فاصله‌ها و فهرست رستوران‌ها **نمونه و حدودی** هستند. پیش از انتشار واقعی، آن‌ها را در `data.py` بررسی و به‌روز کنید (`DAILY_COST` و `TRANSPORT` هم برای برآورد بودجه قابل تغییرند). برای انتشار روی سرور، `SECRET_KEY` را به‌صورت متغیر محیطی تنظیم کنید و از gunicorn یا مشابه آن استفاده کنید.

## قرار دادن ویدیوی پس‌زمینه

فایل ویدیوی خودت را با نام دقیق `background.mp4` داخل مسیر `static/videos/` قرار بده. در بنر بالای صفحه اصلی، ویدیو به‌صورت خودکار، کاملاً بی‌صدا (حتی با تنظیم volume صفر)، تکرارشونده و سازگار با موبایل پخش می‌شود. لازم نیست کدی را تغییر بدهی. اگر فایل ویدیو وجود نداشته باشد یا مرورگر پخش خودکار را مسدود کند، پس‌زمینه گرادیانی فعلی نمایش داده می‌شود. در بعضی مرورگرها شروع خودکار ویدیو فقط پس از تعامل کاربر مجاز است. بهتر است ویدیو MP4 (کدک H.264)، کم‌حجم و افقی باشد.
